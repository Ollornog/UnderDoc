## Reporting a vulnerability

Please report security problems **privately**, not as a public issue.

- Preferred: GitHub's [private vulnerability reporting](https://github.com/Ollornog/UnderDoc/security/advisories/new)
- Alternatively by e-mail: underdoc-github@ollornog.de

Please include what you did, what you expected and what happened instead, plus the version or commit you
tested.

## What you can expect

- **An acknowledgement within 14 days.** This project is maintained by one person in their spare time.
- An assessment of the report and, if confirmed, a fix or a documented mitigation.
- Credit in the release notes, unless you prefer otherwise.

## Supported versions

While the project is below 1.0, only the latest release receives fixes.

## Scope

UnderDoc will hold company documents, personal data and passwords. Reports about these are especially welcome:

- Reading a page, file, list or password without permission, including through embedding or public sharing.
- Reaching internal systems through a configured source.
- Password values appearing anywhere outside their encrypted store.
