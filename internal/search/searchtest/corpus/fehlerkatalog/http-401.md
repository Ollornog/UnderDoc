## Symptom

Eine Schnittstelle antwortet mit HTTP 401.

## Ursache

Das Token fehlt oder ist abgelaufen.

## Lösung

Token neu erzeugen und in der Konfiguration der Schnittstelle hinterlegen.

## Betroffene Systeme

Schnittstellen, Webshop-API
