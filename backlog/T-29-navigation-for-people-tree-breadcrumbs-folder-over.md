# T-29 — Navigation for people: tree, breadcrumbs, folder overview, used in, table of contents

People mostly miss structure, not text (ADR-33): a tree, breadcrumbs, a folder view with its overview page on top, "used in" for pages and files, and a table of contents that marks where the reader is. Front matter and IDs stay hidden; the description shows on top as a summary.
