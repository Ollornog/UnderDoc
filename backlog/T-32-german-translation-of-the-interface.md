# T-32 — German translation of the interface

The interface is English only so far ("English for now"). Every text of the interface comes from an i18n table with English as the source and a German table as the translation, chosen by the browser language and a setting in the profile. A check fails when a text has no German entry or when a German entry has no English source. Dates and numbers follow the language. The rights dialog of T-26 and every later text are included from the start.
