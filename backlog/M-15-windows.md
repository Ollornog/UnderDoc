The content area splits into windows, so documents can be read next to each other.

**Done when this is true:**

- The content area shows 1, 2, 3 or 4 windows as columns.
- Each window has its own document and scroll position, and the same document can be open in two windows.
- Each window shows its table of contents as a side panel, hides it, or offers it as a marker with a drop-down.
- The layout is part of the URL, so it survives a reload and can be sent as a link.
- A phone shows one window at a time.
- **Acceptance: a browser test opens four windows, one document twice, and each one scrolls and navigates on its own.**
