Other systems receive data, and users without SMB reach the files.

**Done when this is true:**

- A read API with tokens, CSV and Excel exports, also as files in the folder.
- Schedules in a configurable time zone, mail reports and webhooks.
- WebDAV over HTTPS with per-user app passwords and the same permissions as the web (ADR-10).
- Check-out in the browser: download, edit, upload with a hash check.
